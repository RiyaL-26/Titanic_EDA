About the Project

This project explores the Titanic passenger dataset using Python. It focuses on data cleaning, missing value handling, statistical analysis, and visualization to understand passenger survival patterns.

Tools & Technologies

Python Pandas Seaborn Matplotlib Data Analysis

What I Analyzed

  • Dataset structure and summary statistics
  • Missing values and duplicate records
  • Passenger survival counts
  • Survival rates by gender and class
  • Passenger age distribution
  • Correlation between numerical variables

Key Questions

  • How many passengers survived?
  • How did survival rates differ by gender?
  • Did passenger class relate to survival?
  • What patterns can we observe in passenger ages?
